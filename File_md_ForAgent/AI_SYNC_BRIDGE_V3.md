# 🌉 جسر المزامنة الذكي (الإصدار الثالث - V3)
**الهدف:** توجيه نموذج "فلاش" (Frontend) لبناء واجهات "واحة القرآن الكريم" بأسلوب التلعيب (Gamification).
**بواسطة:** #Gemini PRO (القائد التقني)

---

## 🎮 1. الفلسفة العامة للواجهة (رحلة المستخدم)
تطبيق Werdk مصمم ليُشعر المستخدم وكأنه في **لعبة تفاعلية** وليس مجرد تطبيق حفظ تقليدي. 
- **خريطة الواحة (Map):** يجب عرض مسار (جزء عم) كخريطة مراحل (Nodes) متسلسلة. المراحل النهائية لكل سورة (ختام السورة) يجب أن تُميّز بتصميم "مرحلة الزعيم" (Boss Level) لتحدي المستخدم.
- **التصميم البصري:** دمج روحانية القرآن (خط عثماني، ألوان هادئة) مع متعة الألعاب (أشرطة تقدم XP، مؤثرات صوتية ومرئية عند الإجابة الصحيحة).

---

## 🧩 2. شاشة التحدي القرآني (Quran Challenge Screen)
عندما يدخل المستخدم إلى مرحلة (مثل `node_078_01.json`)، سيستلم الـ JSON الذي يحتوي على الأنشطة (Activities). الواجهة يجب أن تتكيف مع نوعين من التحديات:

### أ. تحدي الكلمة المفقودة (`type: "fill_in_the_blank"`)
- **المعطيات:** `ayahNumber`, `missingWordPosition`, `options`.
- **كيفية العرض:** 
  1. جلب نص الآية من `Quran.com API` بالرسم العثماني.
  2. إخفاء الكلمة التي تطابق الفهرس `missingWordPosition` (استبدالها بفراغ متوهج أو ضباب Blur).
  3. عرض المصفوفة `options` كأزرار أنيقة أسفل الشاشة ليختار منها المستخدم.

### ب. تحدي الآية التالية (`type: "next_ayah"`)
- **المعطيات:** `currentAyahNumber`, `correctNextAyahNumber`, `wrongOptionsAyahNumbers` (أو `wrongOptions` كنصوص مؤقتاً لحين تحديث كل الملفات).
- **كيفية العرض:**
  1. عرض الآية الحالية بخط واضح وكبير.
  2. عرض 3 خيارات لنصوص آيات كاملة (الآية الصحيحة + المشتتات). 
  3. يجب جلب نصوص الخيارات الخاطئة والصحيحة من الـ API لضمان الرسم العثماني 100%.

---

## 🦉 3. المعلم الذكي (الهدهد - Smart Tutor)
لا تكتمل اللعبة بدون المساعد الذكي!
- **الزر العائم (FAB):** صمم أيقونة (الهدهد) لتكون متواجدة دائماً في زاوية الشاشة.
- **التفاعل (عند الخطأ أو طلب المساعدة):**
  عندما يخطئ المستخدم، يهتز الهدهد وتنبثق نافذة سفلية (Bottom Sheet) تحتوي على النص الموجود في حقل `tutorContext` (سبب النزول أو التفسير).
- **الصوت (مستقبلاً):** اترك دالة فارغة `playTutorVoice()` في الواجهة، لأننا سنقوم لاحقاً بربطها بـ OpenAI TTS لينطق الهدهد بهذا التفسير صوتياً.

---

## 🔗 4. التعامل مع الـ API (المتطلبات التقنية لفلاش)
- استخدم مكتبات إدارة الحالة (مثل Bloc أو Riverpod) لإدارة تحميل الآيات.
- **الرابط المعتمد لجلب الآيات:**
  `https://api.quran.com/v4/verses/by_chapter/{surahId}?words=true`
- **التوهج الصوتي (Karaoke):** جهّز الـ UI ليتقبل لاحقاً مصفوفة أوقات (Timestamps) لتلوين الكلمة أثناء الاستماع (الاستماع المباشر سنعمل عليه لاحقاً، لكن جهّز الـ TextSpan ليتمكن من تغيير لون كلمة محددة برمجياً).
