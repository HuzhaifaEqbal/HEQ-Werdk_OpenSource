## 🎮 1. الفلسفة العامة للواجهة ورحلة المستخدم

تطبيق Werdk مصمم ليُشعر المتعلم بأنه يخوض **تجربة تعليمية تفاعلية مشوقة** تجمع بين قدسية القرآن الكريم وسلاسة الألعاب العصرية:
- **خريطة الواحة (Map):** عرض المسارات التعليمية كخريطة عقد ومحطات متسلسلة، مع تمييز المحطة الختامية لكل وحدة بتصميم مرحلة الزعيم الملكية (Boss Level).
- **التصميم البصري:** خط عثماني واضح، ألوان داكنة فاخرة، وتأثيرات بصرية وسمعية مشجعة عند الإجابة الصحيحة.
- **شاشة الانتظار التفاعلية (AI Loading Screen):** هالة نيون محيطية نابضة (Breathing Neon Aura) باللون الذهبي الملكي أو السماوي، مع حركة الهدهد المفكر وشريط تقدم رشيق وبطاقات نصائح متجددة.

## 🧩 2. أنواع التحديات القرآنية في الواجهة

عند دخول المستخدم إلى عقدة تعليمية، يتم استلام كائن البيانات المحتوي على الأنشطة (Activities):

### أ. تحدي الكلمة المفقودة (`type: "fill_in_the_blank"`)
- **المعطيات:** `ayahNumber`, `missingWordPosition`, `options`.
- **آلية العرض البرمجية:**
  1. جلب نص الآية بالرسم العثماني من الـ API المعتمد.
  2. إخفاء الكلمة المحددة بموقع `missingWordPosition` واستبدالها بمربع فراغ متوهج.
  3. عرض الخيارات (`options`) كأزرار أنيقة ومتباينة أسفل الشاشة، مع إبراز لون النص المختار بوضوح تام.

### ب. تحدي الآية التالية (`type: "next_ayah"`)
- **المعطيات:** `currentAyahNumber`, `correctNextAyahNumber`, `wrongOptionsAyahNumbers`.
- **آلية العرض البرمجية:**
  1. عرض الآية الحالية بخط عثماني كبير في منتصف الشاشة.
  2. عرض 3 بطاقات خيارات لنصوص الآيات التالية (الآية الصحيحة + مشتتات من نفس السورة أو السياق).
  3. جلب نصوص الخيارات الصحيحة والمشتتة من الـ API لضمان التشكيل 100%.

## ⚖️ 3. أنواع تحديات مسار الفقه والأحكام

### أ. شاشات الدروس الاعتيادية (`isBoss: false`):
- تناوب صارم بين بطاقة شرح مفهوم (`concept`) متبوعة ببطاقة سؤال تطبيقي (`question`).
- دعم أربعة أنماط للأسئلة: خيارات متعددة، ملء الفراغات، ترتيب الخطوات، وسيناريوهات فقهية استنتاجية.

### ب. الاختبارات الملكية / تحدي الزعيم (`isBoss: true`):
- يظهر في نهاية كل عقدة أو باب فقهي.
- يتكون من 5 أسئلة استنتاجية شاملة تختبر الفهم العميق والقدرة على تطبيق الأحكام.

## 🦉 4. المعلم الذكي التفاعلي (الهدهد - Smart Tutor)

- **الزر التفاعلي:** أيقونة الهدهد تلازم المستخدم أثناء التعلم.
- **التفاعل التلقائي عند الخطأ:** عند ارتكاب خطأ، يهتز الهدهد وتنبثق نافذة سفلية زجاجية (Glassy Bottom Sheet) تعرض الشرح الإثرائي المستخرج من `tutorContext`.
- **دعم التفاعل الصوتي (TTS Ready):** تجهيز دالة `playTutorVoice()` لاستدعاء الصوت التفسيري ونطقه للمستخدم.

## 🔌 5. دورة حياة الجلسة وإنهاء الدرس (Session Lifecycle & Error Tracking)

- **تتبع الأخطاء:** دمج عداد `_mistakesCount` في دورة حياة الجلسة، واحتساب كل خطأ في الإجابة، مع تصفير العداد عند إعادة المحاولة.
- **إنهاء العقدة:** عند اكتمال الجلسة، يتم استدعاء مسار إنهاء الدرس في الخادم وتمرير معدل الدقة وعدد الأخطاء لتحديث نقاط الـ XP ونسبة فك القفل في الخريطة:
```dart
await learningPathService.completeNode(
  pathId: pathId,
  nodeId: nodeId,
  mistakesCount: mistakesCount,
  totalQuestions: totalQuestions,
);
```
