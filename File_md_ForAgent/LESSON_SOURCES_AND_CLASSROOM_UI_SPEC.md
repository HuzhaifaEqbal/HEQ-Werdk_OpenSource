## 1. عقد ومخطط بيانات المصادر (Lesson Sources Schema)

لكي تظهر المراجع بنجاح للمستخدم بعد إنهاء الدرس في شاشة النتائج (`LessonResultScreen`) أو في بطاقات الشرح، يحتوي الـ JSON الخاص بالدرس (`GET /paths/:pathId/nodes/:nodeId`) على مصفوفة باسم `sources`:

```json
{
  "sources": [
    {
      "book": "متن أبي شجاع (غاية الاختصار)",
      "link": "https://shamela.ws/book/9780"
    }
  ]
}
```

### قواعد التعامل مع المصادر في الواجهة:
- التطبيق يبحث عن المفتاح `book` لعنوان المرجع، والمفتاح `link` للرابط المباشر.
- عند النقر على المرجع، يُفتح الرابط في المتصفح الخارجي المعتمد.
- إذا كانت المصفوفة فارغة أو غير متوفرة، يتم إخفاء قسم المصادر بسلاسة دون التسبب في أي استثناء برمجي.

## 2. معمارية غرفة الصف التفاعلية (Animated Classroom Board)

- **اللوح التفاعلي:** استبدال شاشات المحادثة القديمة بلوح تعليمي تفاعلي غامر يدعم تدرجات الظلام والخطوط المتكيفة، ويعرض الصور والشروحات بوضوح فائق.
- **الهدهد المعلم:** دمج صورة الهدهد المتحركة (`Animated WebP`) مع أنيميشن انزلاقي سلس من الجانب، وفقاعة حوار ترحيبية لامعة تتغير نصوصها ديناميكياً ثم تختفي.
- **سرعة العرض وطباعة النص:** ضبط سرعة التقديم التلقائي وتأثير الآلة الكاتبة لضمان قراءة مريحة للمتعلم.
- **مشغل الأمثلة الصوتية (`AudioExampleWidget`):** شريط صوتي نحيف ومرن يتموضع في أسفل بطاقة المفهوم مع مؤشر تحميل وتشغيل أنيق يتكيف مع الثيم الليلي والنهاري.
