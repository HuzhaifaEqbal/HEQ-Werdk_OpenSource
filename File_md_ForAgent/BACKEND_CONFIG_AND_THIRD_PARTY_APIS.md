## 1. Audio & Reciters API
- **المصدر الأساسي:** `https://mp3quran.net/api/v3`
- **هيكل البيانات الموحد (Unified Endpoint):**
  - بناء نقطة نهاية موحدة في الخادم ترجع قائمة القراء المعتمدين لتحديثها ديناميكياً بدون إصدار تحديث جديد للتطبيق.
  - الحقول الإلزامية لكل قارئ: `id`, `name`, `rewaya`, `server_url`, `image_url`.
- **الصور والأصول:**
  - يتم استضافة صور القراء المفرغة والمقصوصة بجودة عالية على الـ CDN السحابي لترجع روابطها مباشرة من الـ API.

---

## 2. محرك التزامن اللحظي للآيات (Audio Timing Engine)
- **المصدر:** `https://mp3quran.net/api/v3/ayat_timing?surah={surah}&read={read_id}`
- **المعمارية المعتمدة:**
  - يتم جلب ملف السورة الكاملة بصيغة MP3، واستخدام ملف الـ JSON الزمني لعمل `seek()` وتظليل الآيات والنصوص ديناميكياً أثناء القراءة والاستماع، مما يوفر استهلاك البيانات ويمنع التقطيع.

---

## 3. التخزين المحلي والتشغيل بدون إنترنت (Offline Storage)
- مسار الحفظ في الهاتف: `ApplicationDocumentsDirectory`.
- صيغة حفظ الملفات الصوتية: `<Reciter_ID>_surah_<Surah_Number>.mp3`.
- **مزامنة الحسابات:** مزامنة السور المحملة والمفضلة مع الملف الشخصي للمستخدم في السيرفر.

---

## 4. إعدادات التشغيل وتفضيلات المستخدم (Playback Settings Schema)
- حفظ واسترجاع تفضيلات المستخدم:
```json
{
  "user_id": "123",
  "preferences": {
    "default_riwaya": "hafs",
    "default_reciter_id": 102,
    "sleep_timer_default_minutes": 30
  }
}
```

---

## 5. مراجع ومصادر الدروس (Lesson Sources Contract)
- **المتطلب البرمجي:** شاشة نتيجة الدرس في التطبيق تعرض مصادر ومراجع الدرس العلمي للتوسع.
- **عقد البيانات المتوقع (JSON Schema):**
```json
{
  "sources": [
    {
      "book": "فتح القريب المجيب في شرح ألفاظ التقريب",
      "link": "https://shamela.ws/book/9780"
    }
  ]
}
```
*(يعتمد التطبيق على المفتاحين `book` و `link`، وتفتح الروابط في المتصفح الخارجي).*
