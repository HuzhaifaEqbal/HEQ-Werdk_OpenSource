```
المشروع: تطبيق تعليمي إسلامي وقرآني تفاعلي مفتوح المصدر (Digital Waqf)

المسار الحالي: واحة الفقه والعبادات اليومية
```

### هيكل البيانات الإلزامي (JSON):

كل ملف درس = Object يحتوي على مصفوفة `steps` بالتناوب:
- **concept** (بطاقة شرح المفهوم)
- **question** (سؤال اختبار فوري)

```json
{
  "steps": [
    {
      "type": "concept",
      "title": "عنوان المفهوم",
      "content": "شرح علمي دقيق للمفهوم من المصادر الفقهية الموثوقة",
      "example": "مثال فقهي عملي أو قرآني أو حديثي يُقرب الفهم"
    },
    {
      "type": "question",
      "question_type": "multiple_choice",
      "question_text": "سؤال مباشر يختبر المفهوم السابق",
      "options": ["خيار1", "خيار2", "خيار3", "خيار4"],
      "correct_answer_index": 0,
      "explanation": "شرح وافٍ يوضح سبب صحة الإجابة ويفند الأخطاء الشائعة"
    }
  ]
}
```

### قواعد ثابتة لكل توليد:
1. كل درس = 5 بطاقات concept + 5 أسئلة question = **10 steps إجمالاً**
2. التناوب إلزامي: concept ← question ← concept ← question ...
3. المشتتات (الإجابات الخاطئة) لازم تكون **قوية ومنطقية** وليست واضحة الخطأ
4. الشرح في `explanation` يجب أن يُعلّم لا يكتفي بذكر الإجابة
5. المصدر الفقهي: **[المذهب الذي تريده]** (علماً بأن بيانات هذا المستودع مبنية وفق المذهب الشافعي حالياً) مع الإشارة عند الاختلاف المعتبر
6. النتيجة: **JSON خالص داخل كود بلوك** — لا شرح ولا رسائل خارج الكود

**📌 استخدم هذا البرومت لتوليد كل درس من دروس الفقه**

```
أنت خبير في الفقه الإسلامي ([المذهب الذي تريده]) وتصميم مناهج Micro-learning.

المطلوب: أنشئ درساً تفاعلياً كاملاً عن موضوع:
[اكتب الموضوع — مثال: شروط صحة الوضوء]

السياق التعليمي:
- العقدة: [مثال: الطهارة]
- الدرس رقم: [مثال: الدرس الثاني]
- المفاهيم الخمسة التي يجب تغطيتها:
  1. [مثال: ما هي شروط صحة الوضوء وعددها]
  2. [مثال: اشتراط النية في الوضوء]
  3. [مثال: اشتراط الماء الطهور]
  4. [مثال: إزالة ما يمنع وصول الماء]
  5. [مثال: ترتيب الأعضاء وحكمه في المذهب المعتمد]

قواعد إلزامية:
- كل مفهوم = بطاقة concept ثم سؤال question مباشرة
- النتيجة النهائية: 10 steps بالتناوب (concept, question, concept, question, ...)
- المشتتات في الأسئلة يجب أن تكون قوية ومنطقية (لا أجوبة واضحة الخطأ)
- المشتت القوي: خيار صحيح في مذهب آخر، أو قريب من الصحيح لكن ناقص، أو شرط مختلف
- لا تخترع معلومات — استند للمذهب المعتمد لديك ([المذهب الذي تريده] — وبيانات المستودع شافعية) واذكر المصدر إن أمكن

هيكل JSON الإلزامي:
{
  "steps": [
    {
      "type": "concept",
      "title": "عنوان المفهوم",
      "content": "شرح علمي دقيق — 2 إلى 4 جمل — بلغة واضحة مناسبة لمتعلم مبتدئ",
      "example": "مثال فقهي عملي: وضع، أو نص حديثي، أو حالة يومية"
    },
    {
      "type": "question",
      "question_type": "multiple_choice",
      "question_text": "سؤال يختبر المفهوم السابق — الإجابة لا تكون واضحة بدون فهم",
      "options": ["خيار1", "خيار2", "خيار3", "خيار4"],
      "correct_answer_index": 0,
      "explanation": "شرح يوضح سبب الصحة ويفند الأخطاء الشائعة — 2 إلى 3 جمل"
    }
  ]
}

أخرج JSON خالصاً داخل كود بلوك فقط. لا رسائل ولا شرح خارج الكود.
```

```
أنت خبير في الفقه الإسلامي ([المذهب الذي تريده]) وتصميم الاختبارات الشاملة.

المطلوب: أنشئ اختبار Boss Level شاملاً لموضوع:
[اكتب الموضوع — مثال: الطهارة — الوضوء]

الاختبار يجب أن يغطي:
- جميع الدروس السابقة في هذا الموضوع
- أسئلة تربط بين المفاهيم (لا مجرد تكرار)
- مستوى متقدم: السؤال يحتاج تفكيراً لا مجرد تذكر

عدد الأسئلة: 10 أسئلة
نوع الأسئلة: multiple_choice حصراً

معايير المشتتات (الأجوبة الخاطئة):
1. خيار صحيح في مذهب آخر لكن خاطئ في المذهب المعتمد
2. خيار قريب من الصحيح لكن ناقص أو زائد شرطاً
3. خيار يخلط بين مفهومين متشابهين
4. لا تضع أجوبة واضحة الخطأ تماماً

هيكل JSON الإلزامي:
[
  {
    "id": "q1",
    "type": "multiple_choice",
    "question_text": "نص السؤال",
    "options": ["خيار1", "خيار2", "خيار3", "خيار4"],
    "correct_answer_index": 0,
    "explanation": "شرح وافٍ يوضح الإجابة ويبين لماذا الخيارات الأخرى خاطئة"
  }
]

أخرج JSON خالصاً داخل كود بلوك فقط. لا رسائل ولا شرح خارج الكود.
```

# ⚠️ تنبيهات ذهبية للمحتوى الديني

> **1. الدقة فوق كل شيء:**
> البيانات الفقهية يجب أن تُستقى من مصادر معتمدة (الهداية، مراقي الفلاح، الفقه الإسلامي وأدلته).
> لا تقبل أي إجابة من الذكاء الاصطناعي دون مراجعة فقيه أو مرجع موثوق.

> **2. الخلاف الفقهي:**
> عند وجود خلاف بين المذاهب اذكره صراحةً في `explanation` ولا تترك الطالب يظن أن رأياً واحداً هو الوحيد الصحيح.

> **3. المشتتات الخطيرة:**
> تأكد أن الأجوبة الخاطئة ليست مسائل خلافية صحيحة في مذهب آخر دون إشارة — لأن هذا قد يُضلل الطالب.

> **4. المراجعة البشرية إلزامية:**
> كل JSON يُولَّد يجب أن يراجعه شخص متخصص في الفقه قبل النشر.
