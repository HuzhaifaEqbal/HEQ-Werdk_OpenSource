## 🏗️ 1. المكونات المعمارية للمنظومة (Ecosystem Architecture)

1. **الواجهة الخلفية (Backend Core):** خادم Node.js مبني بتقنيات Express و Prisma ORM متصل بقاعدة بيانات PostgreSQL سحابية على منصة الاستضافة.
2. **واجهات التطبيق (Mobile App):** تطبيق Flutter متطور مبني بهوية بصرية داكنة فاخرة، يدعم الروابط العميقة، مشغلات الصوتيات بالخلفية، والأنيميشن التفاعلي.
3. **المصادقة المركزية (SSO Central Auth):** خادم مصادقة مركزي يوفر تسجيل الدخول الموحد لجميع تطبيقات المنظومة عبر بروتوكول تبادل الرموز الآمن.
4. **محرك الذكاء الاصطناعي (AI Engines):** نماذج الذكاء الاصطناعي لمعالجة الأسئلة التفاعلية وتوليد ردود المعلم الذكي اللحظية وسياق الدروس.

---

## 💻 2. خدمات الواجهة الخلفية المعتمدة (Backend Services)

- **الرابط الأساسي للخادم الحي:** `https://your-api-domain.com/api/v1`
- **نظام المصادقة (`authController.js`):** تسجيل الدخول بكلمة المرور، التحقق بكود OTP عبر البريد بقالب HTML فاخر، استعادة كلمة المرور، والمصادقة الموحدة عبر SSO.
- **الملف الشخصي وخطة التعلم (`userController.js`):** استعلامات `GET /me` و `PUT /me` لحفظ وتعديل مسار التعلم وحساب المدة التقديرية للختم.
- **المعلم الذكي (`askTutor`):** استقبال سؤال المستخدم + سياق الدرس الفقهي أو القرآني وتمريره للذكاء الاصطناعي لإرجاع إجابة دقيقة وموثوقة.
- **نظام الجوائز (`Achievement` & `UserAchievement`):** مخطط Prisma لحفظ الجوائز مع ميزة التحديث والمزامنة التلقائية (`Auto-Sync Upsert`).

## 🛠️ 4. قواعد الاستقرار البرمجي والدروس المستفادة

1. **إدارة النصوص والـ String Escaping:** الحذر التام من وضع علامات هروب غير مقصودة في نصوص الـ SQL أو استعلامات Prisma لمنع أخطاء الـ SyntaxError.
2. **استعلامات Prisma (Update vs Data):** الالتزام الصارم بمرور البيانات داخل كائن `data: {}` عند استخدام `.update()` أو `.upsert()`.
3. **قاعدة حماية المحارف العربية (Zero-Terminal Encoding Rule):** حظر تعديل الملفات البرمجية التي تحتوي على نصوص عربية وتشكيل قرآني عبر أوامر الطرفية، والاعتماد على أدوات التحرير المباشرة لضمان سلامة الـ UTF-8.
4. **زرع البيانات (Database Seeding):** عند الحاجة لحقن بيانات جديدة أو بذور، يتم الاتصال بقاعدة البيانات السحابية عبر متغير البيئة `DATABASE_URL` وتشغيل نصوص التغذية لضمان استقرار الخادم الحي.
