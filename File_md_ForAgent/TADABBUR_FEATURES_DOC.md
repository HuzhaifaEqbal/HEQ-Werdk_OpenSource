# 🚀 البرومبت الموجه لنموذج الذكاء الاصطناعي (انسخ هذا الجزء وأرسله للنموذج)

أنت مهندس Flutter خبير في بناء التطبيقات الإسلامية التفاعلية وتجربة المستخدم (UI/UX).
المهمة: قم ببرمجة شاشة "التدبر القرآني والوقفات الإيمانية" (Tadabbur Screen) لتطبيقنا، مع مراعاة المعايير الهندسية والجمالية التالية بدقة:

### 🎯 1. مصادر البيانات المفتوحة (Open APIs Integration):
- استخدم الـ APIs الإسلامية العامة الموثوقة لجلب البيانات:
  - جلب النص القرآني والتفسير الميسر: استدعاء `https://api.alquran.cloud/v1/ayah/{surah}:{ayah}/ar.muyassar` (أو مصدرك المعتمد).
  - جلب الوقفات التدبرية والتطبيقات العملية: تقسيم الوقفات التدبرية إلى نصفين (نصف للوقفات الإيمانية، ونصف للعمل والتطبيق الواقعي) لمنع التكدس البصري في الشاشة.

### 🧹 2. محرك تنظيف وفلترة النصوص (Text Sanitization Engine):
- أنشئ دالة تنظيف صارمة `String cleanText(String raw)` لمعالجة أي نصوص قادمة من الـ API:
  - إزالة كافة وسوم الـ HTML (مثل `<p>`, `<span>`, `<br>`).
  - إزالة رموز الـ Markdown (مثل `*`, `#`, `_`).
  - إزالة المحارف المخفية وفواصل الأسطر غير المرئية (مثل `\ufeff`).
  - التأكد من سلامة التشكيل القرآني دون تشويه.

### 🎨 3. عناصر واجهة المستخدم البصرية (UI Components):
1. **كرت المفسر الزجاجي (Glassy Author Pill):**
   - تصميم كرت بيضوي أنيق بخلفية زجاجية مصنفرة شبه شفافة (`withOpacity(0.12)`) وحواف ذهبية ناعمة، يبرز اسم المفسر أو الهيئة الموثقة للمعلومة.
2. **زر النسخ السريع (Smart Copy Action):**
   - زر `IconButton` أنيق يسمح بنسخ النص المنظف بضغطة واحدة إلى الحافظة (Clipboard) مع إظهار `SnackBar` تأكيد تفاعلي لطيف.
3. **عداد مرات النسخ التفاعلي (Live Copy Counter):**
   - بجانب زر النسخ، اعرض نصاً: `"{count} شخصاً استلهموا من هذه الوقفة"`.
   - اربط الزر باستدعاء خلفي اختياري (Optimistic UI Update) لزيادة العداد بمقدار `+1`.
4. **تذييل إخلاء المسؤولية المعتمد (Disclaimer Footer):**
   - بطاقة ثابتة أنيقة في أسفل الشاشة تحتوي على: *"هذه البيانات مأخوذة من مصادر ومراجع دينية موثقة — [قراءة المزيد]"* مع تمييز رابط القراءة بلون تفاعلي.
5. **الاستجابة للخطوط والثيم:**
   - يجب أن تتجاوب الشاشة مع ثيم التطبيق الداكن والفاتح ومع نظام تكبير الخطوط (`textScaler`).

### 🛠️ 4. المخرجات البرمجية المطلوبة:
- اكتب كود Dart كامل لشاشة `tadabbur_screen.dart` يشمل:
  - الـ State Management (StatefulWidget أو Riverpod/Bloc).
  - نموذج البيانات `TadabburItem`.
  - معالجة حالات التحميل (Skeleton/Shimmer Loading)، الخطأ (مع رسائل عربية ودودة)، وفراغ البيانات.
- لا تستخدم أي مكتبات خارجية معقدة باستثناء `flutter/services.dart` للنسخ، ومكتبة HTTP القياسية.
