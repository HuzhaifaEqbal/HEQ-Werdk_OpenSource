# 🎙️ المعايير الهندسية للمحتوى الصوتي والبصري
## (Audio & Visual Content Standards, CDN Streaming & Media Injection Specification)

> ### 📌 الوظائف والمهام الأساسية لهذا الملف (File Functions & Scope):
> * **استراتيجية الأصول الصوتية القرآنية:** اعتماد EveryAyah وقراء الحرم (الشيخ سعود الشريم والمنشاوي) لشواهد التجويد والفقه.
> * **الصوتيات غير القرآنية (أذكار، أذان، أدعية):** الربط الموثوق مع API حصن المسلم (`hisnmuslim.com`) و API الأذان، وسيرفر CDN المخصص (`werdk-cdn.b-cdn.net`).
> * **استراتيجية الأصول البصرية ثلاثية الأبعاد (Visual Assets):** حظر أكواد الـ SVG العشوائية واعتماد صور PNG/WebP عالية الدقة المولدة بهوية موحدة والمرفوعة على الـ CDN.
> * **صيغة الحقن المعياري في ملفات JSON:** أمثلة حقول `audio_url` و `image_url` في بطاقات المفاهيم.
> * **الفئة المستهدفة:** مهندسو الواجهات الأمامية، مهندسو البيانات، ومطورو الوسائط المتعددة (Multimedia Engineers).

## 1. استراتيجية الأصول الصوتية (Audio Assets)

تعتمد استراتيجية الصوت على توفير تجربة تعليمية تفاعلية تتضمن زر تشغيل (Play Button) في واجهات Flutter لكل مفهوم أو سؤال يتطلب نطقاً أو استماعاً دقيقاً.

### أ) الأمثلة الصوتية القرآنية (Quranic Audio):
- **المصادر الأساسية:**
  - `everyayah.com` (المصدر المعتمد لربط الآيات مباشرة بصيغة MP3).
  - `mp3quran.net` و `alquran.cloud`.
- **القراء المعتمدون:**
  - الشيخ **سعود الشريم** (القارئ الافتراضي لدقة ووضوح مخارج الحروف).
  - الشيخ **محمد صديق المنشاوي** (المصحف المعلم كخيار بديل عند الحاجة).
- **الاستخدام:** شواهد التجويد والآيات القرآنية المستدل بها في دروس الفقه.

### ب) الصوتيات غير القرآنية (Non-Quranic Audio):
تشمل أصوات الأذان، الإقامة، أدعية الوضوء، دعاء الاستفتاح، أذكار الركوع والسجود، التشهد، الصلاة الإبراهيمية، دعاء القنوت، وتكبيرات العيدين:
- **المصادر المعتمدة:**
  1. **API حصن المسلم (`hisnmuslim.com`):** يوفر ملفات MP3 نقية ومسجلة لكل ذكر ودعاء بروابط مباشرة ومستقرة.
  2. **API الأذان (`api.aladhan.com`):** مكتبة صوتية للأذان والإقامة بأصوات مؤذني الحرمين.
  3. **سيرفر CDN المشروع (`werdk-cdn.b-cdn.net`):** المصدر الأساسي للمقاطع الصوتية الفقهية الخاصة والمطابقة للمذهب الشافعي (كالترجيع في الأذان، أو صيغة التشهد الشافعية) لضمان أعلى نقاء صوتي واستقرار دائم:
     `https://werdk-cdn.b-cdn.net/assets/fiqh/audio/[Folder_Name]/[File_Name].mp3`

### كيفية الحقن في الـ JSON:
```json
{
  "type": "concept",
  "title": "صيغة التشهد",
  "content": "التحيات المباركات الصلوات الطيبات لله...",
  "audio_url": "https://werdk-cdn.b-cdn.net/assets/fiqh/audio/02_Salah/tashahhud_shafii.mp3"
}
```

## 2. استراتيجية الأصول البصرية (Visual Assets)

> ⚠️ **تنبيه صارم للموديل الزميل:**
> **تم إلغاء واستبعاد نظام الأكواد البرمجية (SVGs) المضمنة داخل الـ JSON تماماً.**

- **المصدر الأساسي للتوليد:** أداة **Google Flow** لإنشاء أصول بصرية ثلاثية الأبعاد / رسومية بهوية بصرية مستقلة ومتسقة ومخصصة لتطبيق HEQ Werdk بناءً على برومبت وشكل فني موحد.
- **الاستضافة:** يتم رفع جميع الصور الناتجة إلى سيرفر الـ CDN المعتمد بصيغة (PNG / WEBP عالية الدقة).
- **بنية الرابط على الـ CDN:**
  ```
  https://werdk-cdn.b-cdn.net/assets/[Section]/[Folder_Name]/[File_Name]
  ```
  - *مثال:* `https://werdk-cdn.b-cdn.net/assets/fiqh/01_Taharah/water_divisions.png`

### كيفية الحقن في الـ JSON:
```json
{
  "type": "concept",
  "title": "أقسام المياه",
  "content": "تنقسم المياه في الفقه الشافعي إلى أربعة أقسام...",
  "image_url": "https://werdk-cdn.b-cdn.net/assets/fiqh/01_Taharah/water_divisions.png"
}
```
