## 📖 مقدمة عامة | General Introduction

### 🇸🇦 بالعربية
مرحباً بك في **المنظومة الإسلامية الرقمية المفتوحة (HEQ Werdk Open Source - Digital Waqf)**.  
هذا المستودع هو وقف تقني مفتوح المصدر يهدف إلى تزويد المطورين، مهندسي البرمجيات، والباحثين بأكبر مكتبة بيانات ومناهج إسلامية تفاعلية مصممة وفق أحدث معايير التعليم المصغر والألعاب التعليمية (Gamified Micro-learning)، والمطابقة للرسم العثماني المعتمد والمصادر الفقهية والتاريخية المحققة.

تستطيع من خلال هذا المستودع استدعاء كافة البيانات والدروس التفاعلية **مباشرة في تطبيقك أو موقعك بـ 3 أسطر كود فقط** عبر شبكة الـ CDN العالمية المجانية، دون الحاجة لإنشاء سيرفرات معقدة أو قواعد بيانات مكلفة!

### 🇬🇧 In English
Welcome to the **Open Islamic Tech Architecture & Datasets Ecosystem (Digital Waqf)**.  
This open-source repository serves as a permanent Digital Waqf offering verified, production-ready educational datasets for Islamic and Quranic software engineers. Designed according to modern gamified micro-learning standards, our datasets cover Quran memorization, verified Shafi'i jurisprudence, rules of Tajweed, and chronological Prophetic Seerah.

Developers and web platforms can consume these datasets directly using **3 lines of code** via our global high-speed CDN, eliminating the need for dedicated backend infrastructure.

## 💻 أكواد الاستدعاء الجاهزة للنسخ | Copy-Paste Integration Snippets

### 📱 1. في تطبيقات Flutter / Dart
```dart
import 'dart:convert';
import 'package:http/http.dart' as http;

class IslamicDataService {
  static const String cdnBase = 
      'https://cdn.jsdelivr.net/gh/HuzhaifaEqbal/HEQ-Werdk_OpenSource@main';

  /// استدعاء فهرس أي مسار ديناميكياً (tajweed / fiqh / quran_oasis / AlSera_Alnabaoia)
  static Future<Map<String, dynamic>> fetchManifest(String track) async {
    final response = await http.get(Uri.parse('$cdnBase/$track/manifest.json'));
    if (response.statusCode == 200) {
      return jsonDecode(utf8.decode(response.bodyBytes));
    }
    throw Exception('Failed to load $track manifest');
  }

  /// استدعاء أي درس JSON محدد
  static Future<Map<String, dynamic>> fetchLesson(String path) async {
    final response = await http.get(Uri.parse('$cdnBase/$path'));
    if (response.statusCode == 200) {
      return jsonDecode(utf8.decode(response.bodyBytes));
    }
    throw Exception('Failed to load lesson from $path');
  }
}

// مثال عملي للاستخدام:
void loadSample() async {
  // جلب درس أحكام النون الساكنة والتنوين
  final lesson = await IslamicDataService.fetchLesson(
    'tajweed/03_Nun_Sakinah_and_Tanween/01_izhar_halqi.json'
  );
  print('عنوان المفهوم: ${lesson['steps'][0]['title']}');
}
```

### 🌐 2. في تطبيقات الويب (JavaScript / TypeScript / React / Next.js / Vue)
```typescript
const CDN_BASE = 'https://cdn.jsdelivr.net/gh/HuzhaifaEqbal/HEQ-Werdk_OpenSource@main';

// Generic Fetcher function
export async function getIslamicCurriculum(filePath: string) {
  try {
    const response = await fetch(`${CDN_BASE}/${filePath}`);
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    return await response.json();
  } catch (error) {
    console.error('Failed to fetch dataset:', error);
    throw error;
  }
}

// Example: Fetch Taharah Lesson 1
getIslamicCurriculum('fiqh/01_Taharah/01_water_and_purity.json')
  .then(data => console.log('Loaded Steps Count:', data.steps.length));
```

### 🐍 3. في لغة بايثون (Python Backend / AI Ingestion)
```python
import requests

CDN_BASE = "https://cdn.jsdelivr.net/gh/HuzhaifaEqbal/HEQ-Werdk_OpenSource@main"

def fetch_json(file_path: str) -> dict:
    url = f"{CDN_BASE}/{file_path}"
    response = requests.get(url)
    response.raise_for_status()
    response.encoding = 'utf-8'
    return response.json()

# Example: Fetch An-Naba Quran Node
node = fetch_json("quran_oasis/juz_30/node_078_01.json")
print(f"Surah ID: {node['surahId']} - Title: {node['title']}")
print(f"Activities: {len(node['activities'])}")
```

## 🛡️ المبادئ والضوابط الشرعية | Sacred & Scholarly Principles

1. **حظر بعثرة القرآن الكريم (No Scrambled Verses):** جميع الأنشطة القرآنية تراعي قدسية كلام الله عز وجل، وتعتمد حصراً على التلاوة، ملء الفراغات الموجهة، وتخمين الآية التالية.
2. **التحقيق والتوثيق المرجعي (Classical Citations):** كافة المسائل الفقهية معززة بالمراجع الشافعية المعتمدة (متن أبي شجاع، فتح القريب، كفاية الأخيار) مع روابط مباشرة للمكتبات التراثية الرقمية.
3. **الثبات التاريخي في السيرة:** الاعتماد على المشهور والثابت في سيرة الحبيب المصطفى ﷺ مع بيان المسائل المختلف فيها دون جزم متكلف.
